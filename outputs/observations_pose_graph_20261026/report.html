5. Method and assumptions

The adapter calls the existing tag_mapping.synchronization.synchronize, graph.build_graph, solver.solve and reporting.evaluate/export_results. The backend is explicit Gauss–Newton with right SE(3) updates, undamped sparse LSMR, block Huber loss and backtracking, following the usual relative-pose least-squares formulation. No replacement optimiser was used. Two numerical fixes were needed in the existing solver: a dense rank SVD for moderate graphs and column scaling of the linear unknowns. Neither adds damping or changes the fitted objective.

  • 230 drone pose nodes, 3 tag nodes, 160 pixel observation factors, 229 motion factors, one anchor prior, one start-height prior and one start-attitude prior. All accepted camera frames retain their own pose. Motion support is sampled at 1-second minimum intervals.
  • Start XY is fixed at (0, 0); initial attitude and height have finite priors. All positions and full attitudes are rotated by −17.4376° to use the recorded start-forward/right axes. This is an initial-frame conversion, with no alignment to held-out ground truth.
  • Use the archive's 25° camera pitch, 0.020 m forward lever arm and 0.120 m tag side length. Intrinsics/distortion are the existing repository 320×240 checkerboard calibration. The archive does not provide its own independent calibration identifier.
  • Floor datum is approximate: assume native PX4 Z=0 is the floor. Start height is the telemetry proxy 0.02463 m, with an assumed 0.050 m prior sigma. The recording has no independent measured floor/body-height datum.
  • Exposure timing is unverified. The existing legacy replay path uses recorded host-derived epochs. Maximum bracket gap is explicitly 1.1 seconds to cover the 1.0283-second logged gap. Fifteen duplicate host-time telemetry rows are coalesced by retaining the final snapshot at each timestamp. Original inputs are unchanged.
  • Existing fallback odometry sigmas are 0.10 m translation and [0.05, 0.05, 0.08] rad rotation per 0.1 s, scaled by √(Δt/0.1). Corner sigma is 0.7 px. Anchor XY sigma is assumed 0.01 m. These are heuristic weights, not calibrated uncertainty or independent PX4 samples.
  • Tags 0, 2 and 3 ground-truth positions are opened for evaluation after fitting. Only tag 1 supplies ground truth to the graph. Rank is verified full; robust cost decreases on all accepted steps. The reported optimisation status is converged_cost.

Validation: 23 mapper solver, geometry, replay and end-to-end tests passed. One live-recorder test was excluded because pymavlink is not installed; no live recording was needed for this analysis. The real dataset also passes convergence, full-rank, monotone accepted cost, exact floor Z, fixed start XY and held-out-survey separation checks.
